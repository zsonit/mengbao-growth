# 萌宝成长 · 儿童成长助手（iOS + Android）

记录孩子成长的双端原生应用：iOS 用 SwiftUI，Android 用 Kotlin + Jetpack Compose。
两端页面、功能、交互一一对应，数据只存在手机本机、不上传云端，JSON 备份可互相导入。

## 功能

- **生长记录**：身高 / 体重 / 脚长 / 头围，按日期保存、可编辑删除
- **生长曲线**：纯 Canvas 绘制的百分位带（P3–P97）+ 实测折线
  - 0–5 岁：WHO 生长标准（LMS 法，按性别月龄逐点计算）
  - 5–7 岁：中国 7 岁以下儿童生长发育参照标准
  - 7–18 岁：WS/T 423 身高发育等级评价
  - 生长速度（年化）、18 岁身高预测（靶身高法 / 百分位外推）
- **喂养记录**：睡眠 / 亲喂 / 瓶喂 / 尿布，今日汇总 + 最近 7 天柱状图
- **接种计划**：广东省执行 · 国家免疫规划 2025 版共 22 剂，点击打卡、到期提醒
- **接种门诊速查**：常见门诊离线名录，可搜索、按城市筛选、打电话
- **附近接种点（粤苗官方 · 实时定位）**：内嵌广东省疾控中心「粤苗」官方接种门诊页，定位查附近门诊、门诊地图、官方权威名单，**无需自己维护门诊数据**（两端主入口都是粤苗）；安卓另留一个「内置门诊地图（离线备用）」入口，粤苗页打不开时兜底
- **鞋服尺码**：脚长自动换算中国码 / 欧码 / 内长，身高对应衣服码
- **换牙档案**：20 颗乳牙拟真牙弓图（总牙数 28 颗，其中乳牙 20 颗），按月龄自动标出临近换牙 / 超期未换，点一颗牙记录脱落日期；附换牙时间表
- **门诊定位（安卓）**：一键同步广东省全省接种门诊（粤苗官方公开接口，免登录，含名称/地址/电话/经纬度，存本机），与内置名录合并、可搜索、按距离排序、一键高德导航；iOS 延用内嵌粤苗官方页定位
- **运行日志（双端）**：独立开关（默认关，崩溃记录不受开关限制），「我的 → 运行日志」可查看 / 导出 / 清空，方便反馈问题
- **阶段重点**：按月龄给出育儿关注点，一键加入待办
- **多宝宝**：支持多个孩子档案自由切换
- **数据管理**：JSON 备份 / 恢复、CSV 导出（发给医生看）；升级直接覆盖安装数据不丢

## 没有 Mac 怎么编译？

本仓库用 **GitHub Actions 的 macOS 机器**自动编译：

1. 推送代码到 `main`（或手动触发 Actions 里的 *Build IPA*）
2. 构建完成后，在 **Actions → Build IPA → Artifacts** 下载 `MengBao-ipa-unsigned`
3. 得到的是**未签名 IPA**（`MengBao-unsigned.ipa`）

### 装到 iPhone 上（免开发者账号）

未签名 IPA 不能直接安装，需要用你的 Apple ID 重新签名（免费 Apple ID 即可，7 天有效期，到期重签）：

| 工具 | 平台 | 说明 |
| --- | --- | --- |
| [Sideloadly](https://sideloadly.io) | Windows / Mac | 连接 iPhone，拖入 IPA，输入 Apple ID 自动签名安装 |
| 爱思助手 | Windows | 「自签安装」功能，同样输入 Apple ID |
| AltStore | iOS / Mac | 需常驻一台电脑刷新签名 |

> 想要长期有效 / 上架 App Store，需要 Apple Developer Program（$99/年），并在
> `.github/workflows/build-ipa.yml` 中加入证书签名步骤（P12 + 描述文件），
> 欢迎提 issue 一起加。

## 地图与定位（高德）

App 用高德 iOS SDK 做地图、定位与周边门诊检索：`AMap3DMap`（地图）+ `AMapSearch`（POI 搜索）。

### Key 配置

Key 写在 `project.yml` 的 `info.properties`，编译进 `Info.plist`，代码里通过 `MapConfig` 读取：

| 项 | 用途 | 说明 |
| --- | --- | --- |
| `AMapIOSKey` | **iOS 平台 Key** | 地图渲染、定位、周边搜索都用它。**必须和高德控制台里绑定的 Bundle ID 一致** |
| `AMapWebKey` | Web 端（JS API）Key | 只用于网页版地图，原生 App 内不会调用（平台类型不匹配会被高德拒绝） |

### 附近接种点（粤苗官方页）

打开路径：「接种」页顶部 **📍 粤苗官方 · 定位查接种门诊**（「接种门诊速查」页顶部也有同一入口）。
内嵌的是 `ymapp.cdcp.org.cn` 的粤苗 H5（接种门诊 / 门诊地图两个标签页）。iOS 端 WKWebView 原生不支持网页定位 API，App 里用 CoreLocation 做了桥接；Android 端走系统定位权限 + WebView 授权回调。也可以点右上角在系统浏览器打开。

- **打开即定位**，按当前位置实时检索周边接种单位；范围自动 **3 → 8 → 20 → 50 公里** 逐级扩大，直到有结果
- 同时检索三类承担接种的单位：**预防接种门诊 / 社区卫生服务中心 / 卫生院**，合并去重
- 结果按**距离排序**，底部面板可展开完整列表；每人一行显示距离、地址、电话
- 点卡片或行 → 地图飞到该院；**一键唤起高德导航**（没装高德则走网页版）；有电话可直接拨号
- 也可以手动选 3 / 5 / 10 / 20 公里，或输入关键词（医院、路名、区名）单独搜索
- **不需要预先同步、不下载几千条名单**；断网或检索失败时自动回落到内置 21 家门诊，功能不空白

「接种门诊速查」页保留的是一份**离线名录**（常见门诊的地址与电话），没网、或想先打电话问清楚时用。
数据来自高德 POI 检索，与「粤苗」官方名单可能存在个别差异（门诊合并、搬迁、新增）；
**预约挂号与免疫规划疫苗仍以「粤苗」小程序为准**。

### 版本号与 Bundle ID（重要，避免重复配置）

| 项目 | 规则 | 改它要不要重新绑定高德 Key |
| --- | --- | --- |
| `MARKETING_VERSION`（2.8.0） | 每次发版递增 | **不用** |
| `CURRENT_PROJECT_VERSION`（build 12） | 每次构建递增 | **不用** |
| `PRODUCT_BUNDLE_IDENTIFIER` | 永久固定 `com.zsonit.mengbao` | **要**（改包名才需要去高德控制台同步） |

也就是说：**发新版本只改版本号即可，高德 Key 的绑定完全不用动**。
只有包名（Bundle ID）变动时才需要去高德控制台重新填一次，所以本项目把包名定死、不再改。
如果地图页底部报错，会直接显示「当前包名 xxx」，方便一眼看出是否被侧载工具改写过包名。

### ⚠️ 地图不出图怎么办

高德 iOS Key 是**按 Bundle ID 绑定**的。当前 App 的 Bundle ID 是 `com.zsonit.mengbao`。
如果地图空白、底部提示「地图加载失败」，去 [高德控制台](https://console.amap.com/dev/key/app) 把该 iOS Key 的 Bundle ID 改成 `com.zsonit.mengbao`（或反过来改本项目的 Bundle ID 去匹配 Key）。

### 隐私

定位只用于「算距离、找附近门诊」，用 CoreLocation 单次定位，不后台常驻、不上传、不落盘。
高德 SDK 已在启动时调用 `MAMapView.updatePrivacyShow/updatePrivacyAgree` 完成隐私合规声明。

## Android 版（Kotlin + Compose）

- 包名 `com.zsonit.mengbao`，版本 `2.8.0 (25)`，minSdk 26（Android 8.0+），targetSdk 34
- 源码在 `android/`，用 Gradle 8.7 + AGP 8.5.2 + Kotlin 2.0 + Compose BOM 2024.06
- 页面与 iOS 完全对应：成长（首页）/ 喂养 / 接种 / 我的 四个 Tab，加上生长曲线、记录编辑、门诊速查、附近接种点、历史、宝宝档案、尺码、待办、阶段重点
- 数据同样只存本机（`files/MengBao/state.json`），**JSON 备份格式与 iOS 完全一致**（日期按 2001-01-01 参考秒编码），可以 iOS 导出 → Android 导入

### 本地构建

```bash
cd android
export JAVA_HOME=/path/to/jdk17
export ANDROID_SDK_ROOT=/path/to/android-sdk
./gradlew :app:assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

> 工程路径含中文时，`gradle.properties` 里需要 `android.overridePathCheck=true`（已加）。

### 安装

APK 用 debug 签名，可以直接装：手机「设置 → 允许安装未知来源应用」→ 打开 APK 安装。
换手机 / 重装不会自动迁移数据，请先在「我的 → 数据备份」导出 JSON。

### Android 的地图与定位

iOS 版内嵌高德地图 SDK；Android 版内嵌地图需要**高德「Android 平台」Key**，并且要绑定
`包名 com.zsonit.mengbao + 签名 SHA1`（调试签名与正式签名不同）。没有 Key 时：

- 「粤苗门诊查询」照常工作：内嵌官方页，需要网络；无网时用离线速查名录
- 顶部提供「🗺 在高德地图搜索附近『预防接种门诊』」，跳转高德实时检索全部单位
- 想要 App 内嵌地图：去高德控制台建 Android Key，把 SHA1 填进去，然后把 Key 写进
  `android/gradle.properties` 的 `amap.android.key=xxx` 重新打包即可
